# NoCookies
An experiment into restoring users sessions without cookies.

This code is just an example of an idea I had to try and replace cookies with browser fingerprinting. I'm not actually sure which would be least ethical, cookies saved on a user PC that can be deleted by the user, or a fingerprint generated by the site that changes nothing on the users device. Anyhow, the code is far from a production level but the interesting parts from a browser fingerprint point of view are:
 - assets/js/nocookies.js [Creates the browser fingerprint and sends with a request to the server]
 - assets/php/nocookies.php [Handles the server / session management]

If you want to test the demo:
 - Clone the git to your local system
 - Modify the database connection in nocookies.php for your server.
 - Create a database and import the supplied sql file.
